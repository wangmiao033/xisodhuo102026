# 献身

## 故事简介

妹妹从医院失踪后，林默在一场陌生直播里听见了她的声音。他循着线索寻找，却被困进了深渊剧场，成了供人围观的求生主播。在这里，观众一张票，就能改掉他的骨骼、声音，甚至记忆。眼看镜中的自己逐渐变成陌生女人，他终于找到了妹妹——她已经忘了他，还在按观众的要求微笑。为了把她带回家，林默开始钻规则的漏洞、争取观众的选票，一步步闯进剧场后台。可每靠近妹妹一点，他就少记得一点自己的过去。等他终于找到出口，还会记得要带谁走吗？

## 阅读提示

《献身》是一部长篇规则怪谈，预计300章，分为十卷。故事从林默寻找妹妹开始，逐步展开深渊剧场、现实中的异常，以及兄妹为找回彼此付出的代价。

开篇先跟着林默解决两个问题：妹妹在哪里，他怎样活过下一场直播。剧场的来历和妹妹的遭遇，会随着他的调查逐渐揭开。

阅读时，可以留意三件事：

- **规则的原话。** 林默能否脱困，常常取决于他怎样理解和利用规则。
- **观众的投票。** 屏幕另一端的人能直接改变他的处境，也会影响他的身体。
- **身份与记忆。** 镜中人的样子、熟悉的声音和系统显示的信息，都值得留意。
