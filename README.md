# 深渊直播：观众正在把我变成女人

**English title: My Horror Livestream Audience Is Turning Me into a Woman**

原工作名：《献身》。

## 故事简介

妹妹从医院失踪后，退伍军人林默在一场直播里听见了她的声音。他追过去找人，却成了深渊剧场的新主播。观众投票，他的骨骼就被改写；下一轮，他们要把他变成女人，连他记得自己是男人的那部分记忆也不肯放过。林默开始抠规则的原文，找漏洞，和弹幕讨价还价。他得先保住自己的名字，才能找回那个已经不认识他的妹妹。可剧场给他的每一次选择，都有人在屏幕另一端等着看他后悔。

## 阅读提示

本书是一部长篇规则怪谈，预计300章，分为十卷。故事从林默寻找妹妹开始，逐步展开深渊剧场、现实中的异常，以及兄妹为找回彼此付出的代价。

开篇先跟着林默解决两个问题：妹妹在哪里，他怎样活过下一场直播。剧场的来历和妹妹的遭遇，会随着他的调查逐渐揭开。

阅读时，可以留意三件事：

- **规则的原话。** 林默能否脱困，常常取决于他怎样理解和利用规则。
- **观众的投票。** 屏幕另一端的人能直接改变他的处境，也会影响他的身体。
- **身份与记忆。** 镜中人的样子、熟悉的声音和系统显示的信息，都值得留意。
