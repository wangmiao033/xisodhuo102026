# 献身

## 故事简介

林默的身体该变成什么样，由屏幕另一端的人投票决定。

他被困在一场无法关闭的直播里。镜面走廊、换装游戏、无声房间，每过一关，观众都能从他身上拿走一点东西。

起初是骨骼和声音。后来，连记忆也能改。

镜子里的男人越来越陌生，系统却告诉他：适配良好。

林默开始把自己的名字、年龄和过去写下来。他得记住自己是谁，也得找到妹妹——入场前，她还在催他吃饭；进入剧场后，他收到的第一条消息却是：

“别让他们知道我在这里。”

他不知道发消息的是谁。这里连镜子都会用妹妹的声音叫他。

直到另一场直播中，一个叫小鹿的主播，在他受伤时下意识伸出了手。那个动作，他见过无数次。

可她不认识他。

林默决定留在镜头前。只要直播还在继续，他就还有机会接近她。

屏幕上，新一轮投票已经开始。
