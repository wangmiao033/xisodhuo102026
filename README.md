# 献身

## 故事简介

退伍军人林默被卷入深渊剧场，成了供人围观的求生主播。在这里，观众一张票，就能改掉他的骨骼、声音，甚至记忆。眼看镜中的自己逐渐变成陌生女人，他却在另一场直播里找到了失踪的妹妹——她已经忘了他，还在按观众的要求微笑。为了把她带回家，林默开始钻规则的漏洞、争取观众的选票，一步步闯进剧场后台。可每靠近妹妹一点，他就少记得一点自己的过去。等他终于找到出口，还会记得要带谁走吗？
