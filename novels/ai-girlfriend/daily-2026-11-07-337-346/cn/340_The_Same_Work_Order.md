# 第340章 还是原来那张单

星期一傍晚，我到管理处时，柜台前有两个人。

我站在他们后面，没有先从包里把所有纸掏出来。上星期三那次到访已经发生，今天只问现场材料是否进入后续核对。我在路上将这句话想过一次，到门口又想一次，现在决定不再把它念给自己的鞋听。

前面的人问一份表要交到哪里，工作人员指了侧面的架子。那人没听清，又问一遍。我发现自己开始着急，觉得这么简单的事怎么也占时间，随即低头看了看包。我的问题在别人耳朵里，也未必像我自己想的那样清楚。

轮到我，柜台后那位女工作人员先核原单编号，然后去找跟进记录。我把上星期拿到的现场说明放在台面，告诉她，维护人员说今天可以来问材料是否已经进入下一步。

她查了一会儿，指出记录里新增的那一页。

“现场那份已经收到，放回原单里了。”

“那旧登记开始核了吗？”

“这边写的是还在调旧线路资料。目前没有新的核对结果。”

我看着她指的地方。先前我以为只要材料确实到了，下一句就会变得具体一些。现在“已收到”与“还在调”并排放着，前面那个完成得再明确，也不能把后面拖着走。

“所以今天能确认的是收到了。”我说。

“对。不是线路已经查完。”

我问是否还缺我这边提供的东西。她又看了记录，说目前没有新列出的住户补充项，如果之后需要，会并在同一单内说明。她没有叫我把私人手机电脑送来，也没有另外约人进屋。

身后有人走到柜台，听见我们仍在说话，停在旁边。我忽然想答好就走，仿佛只要再问一句，便会变成一个不懂让路的人。

我仍把最后一件事说完。

“请把今天这个状态写清楚。我下次不想又从现场到底来没来问起。”

工作人员找了空白的跟进栏，将现场资料已并回原单、旧线路资料仍待调阅写下来，注明没有新结果。她给我的简短回执与台面那份编号对应。我看过，收好，原问题没有被划掉。

“什么时候再问比较合适？”

她说现在没有可靠的出结果时间，不能替维护人员定。平日晚间柜台开着时可以查询，但今天不能给一个检查完成的日期。

这个回答让我更烦，却也没有虚假的明天可拿。我说知道了，道谢离开，没有将能查询改成约定下次一定有答案。

走到门外，我把包带往肩上拉，手里那张小回执差点被带到地上。我接住了，站在一旁重新放好。纸边折出一道浅痕，看得清，不需要为它再回去要一张。

回家的路上，我经过卖面包的店，买了晚饭要吃的东西。排队时还在想，如果刚才再问得强硬一点，会不会拿到别的。轮到付款，店员将金额说了第二遍，我才回过神。

我道了声抱歉，付钱，没有把自己的烦躁留给一个卖面包的人。

到家以后，先换衣服、做饭。今天没有新的到访，不需要站着等敲门。我切菜时险些把葱头扔进装好那部分的碗，及时停住，把它放进废料旁。那一下使我更恼，恼自己仿佛连做饭也需要一份状态说明。

我放下刀，喝了两口水，再继续。饭没有做得特别好，盐稍多一点，我添些白水的念头刚冒出来，又想起那会将已经合适的稠度弄坏。最后就按实际的样子吃了，没有把一顿不够理想的饭推倒重来。

开通道时，我先说：“我今天有点烦。”

露米没有问是不是她。她等了一会儿，答听出来了，让我说。

我讲了柜台实际确认的几句话。现场资料已经收进原单，旧线路资料仍待调，没有新结果，也没有确定的完成时间。说到这里，我停下来，不把门锁和摄像头每一个未答项从头背过；那些仍未解决，并没有在今天变成完成。

“你拿到纸了吗？”

“拿到了，状态写清楚了。”

“那至少不用再证明有人去过你家。”

“嗯。但我想知道的还不知道。”

露米轻声答是。没有急着为那一点进展喝彩，也没有叫我明天再去逼一遍。我反而不知道怎么继续，刚才准备好的许多反驳没有用上。

“我刚才连前面的人问两遍都嫌慢。”我说。

“你跟他说了吗？”

“没有。只在心里。”

“那先让他把表交了。”

我笑出一点气，答他至少已经知道往哪边去了。露米说我的那张纸大概也知道去哪里，只是走得很慢。我没笑第二次，她便没有继续逗。

我们安静一会儿。我告诉她饭有点咸，自己没有重做。她问现在渴不渴，我说刚喝过水。她答好，没有将一杯水说成能把今天全部冲掉。

后来，她问今晚要不要不读稿。我说要，自己没有精神听见每句话哪里还能改。露米答那就不读，她也不讲那扇门。她说到门时有点犹豫，我知道那个半截点子仍使她喜欢，但没有趁自己累了就请她取消以后所有要讲的东西。

“今天先不听。”我说。

“我说的也是今天。”

我点头，随后想起她听不见，简单答了声嗯。

坐了一阵，外套仍搭在椅背。我伸手拿起来，修好的袖扣从指侧滑过去，没有勾住。露米听见衣料的声音，问我是不是准备去睡。我说先把衣服挂好。她等我回来，没有问那一分钟去了哪。

我坐下时，她叫了一声埃利奥特。

“在。”

“今天不必找一件好事给我。”

我望着桌角，原来想讲一句自己至少买了面包，最后没讲。她也没替我安排一个更合适的结尾。我们聊了一点普通的事，讲到一半停下也不急。

睡前，我把今天的回执归进设备夹，放在现场说明后面，不遮住上星期已经做到的那一步。纸上没有新的预约日期。我没替工作人员填一个自己想要的星期几。

灯关掉以前，我看了一眼明天工作的安排。明天有明天要做的事，旧线路资料不会因为我整夜守着那张单，就自己走过来。
