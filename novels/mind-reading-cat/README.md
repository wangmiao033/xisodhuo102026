# My Mind-Reading Cat Is Trying to Set Me Up with the Vet

This directory contains the English reboot of the novel (Novelpia novel 6408), planned as a 250-chapter story. The first release set comprises complete English Chapters 001–035.

- `chapters/en/`: active English chapter manuscripts; the first Markdown heading supplies the chapter title and is omitted from the publication body.
- `manifest.json`: chapter paths, headings, word counts, and exact original file hashes. Word counts use the manifest generator's Unicode word-token rule and may differ slightly from editor counts.
- `CANON.md`: English names and continuity constraints for this edition.
- `REVIEW.md`: review scope and publication boundary.
- `archive/original-2026-10-26/`: unchanged original public chapter bodies and sanitized public metadata, not active reboot manuscripts.

This archive commit is not evidence that an online chapter has been replaced. Publication requires separate per-chapter reader-page verification. Other novels and historical archives are not modified.
